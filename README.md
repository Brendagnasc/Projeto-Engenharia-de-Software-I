# ProjetoBCC322 – Engenharia de Software I

Este é um projeto de exemplo desenvolvido em **C++**, utilizando **GitFlow**, **Makefile** e **Desenvolvimento Dirigido por Testes (TDD)**. O projeto foi criado como atividade prática do curso de Engenharia de Software I.

---

## Objetivos do Projeto

- Aprender a criar e organizar um **repositório Git/GitLab** seguindo boas práticas.  
- Estruturar um projeto C++ com **src, include, bin, test e doc**.  
- Implementar funcionalidades seguindo **TDD**.  
- Controlar o fluxo de desenvolvimento com **GitFlow** (master, develop, staging).  
- Criar e gerenciar **issues e boards** para rastrear mudanças.  
- Aprender a automatizar compilação e testes usando **Makefile**.
